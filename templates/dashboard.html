🤖 Бот оформления рассрочек (okcrm_bot)
Обходит замороженные заказы (банк «Фирма рассрочка», р/с): вписывает взнос, генерирует платежи и документы, загружает на Google Drive, меняет статус на «Новый»
{% if not cfg.IS_CLOUD %}
🔑 Сессия OkCRM
Сессия CRM периодически протухает. Перед захватом вручную открой Chrome с флагом --remote-debugging-port=9222 и войди на CRM. Google Drive больше не нужен — документы загружаются через сервисный аккаунт.
{% else %}
🔑 Сессия OkCRM (облако)
В облаке Chrome недоступен. Захвати сессию OkCRM локально (кнопка «Захватить сессию» в localhost:5000), затем вставь сюда содержимое файла okcrm_bot/storage_state.json (принимается и base64). Файл живёт до следующего передеплоя. Сессия Google Drive не требуется — загрузка идёт через сервисный аккаунт.
{% endif %}
